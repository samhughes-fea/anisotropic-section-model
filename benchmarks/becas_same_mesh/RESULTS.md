# ASM solid section against BECAS on the same meshes: results

Generated by `run.py`. `rel` is ASM / reference - 1 in %. `max scaled` is the largest `|K_ij(ASM) - K_ij(ref)| / sqrt(K_ii K_jj)` over all 36 terms, so a coupling is judged against the diagonal terms it couples. Matrices are in BECAS's order `[Vx, Vy, N, Mx, My, Mz]`; centres in the mesh's own coordinates and their difference as a fraction of the section's size.

**BECAS has not been run on these meshes yet** (no MATLAB or Octave where this was generated). The comparisons below are against BECAS's published values and VABS.
